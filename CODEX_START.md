# Trading Journal: переход с Claude Code на Codex

Проект изучен и подготовлен для продолжения разработки в Codex.

Главный вход — **AGENTS.md**. Важные решения, актуальный срез и очередь —
**docs/codex-context.md**. Порядок открытия проекта и проверок —
**docs/codex-workflow.md**. Фактическая проверка этой подготовки —
**docs/codex-validation.md**.

Если получен `trading_codex_setup.zip`, распаковать его содержимое в
существующий корень **trading_bot**, рядом с `app/`, `docs/`, `.git/` и
`CLAUDE.md`, затем открыть эту папку в Codex и начать новую сессию.
ZIP содержит только добавленные инструкции и конфигурацию, не весь проект.

Это перенос рабочего контекста разработки. Исходный торговый код,
история Git, документация и настройки Claude сохранены. Продакшн не менялся.
Внутренний Anthropic-клиент бота сохранён: смена помощника разработки
не меняет ИИ-провайдера продукта.

Windows-окружение проверено 30.10.2026: Python 3.12.10, PostgreSQL 18.6,
отдельная БД trading_bot_test. Полный локальный гейт: pytest 2635 passed /
0 failed / 0 skipped; smoke 102/102 ×2; ruff 4976 и mypy 60 — существующий
долг без изменений. Отчёты и путь постоянного архива — в
docs/codex-validation.md. Продакшн не проверялся и не менялся; подготовка
Codex и push в резервный репозиторий не выполняют деплой.
