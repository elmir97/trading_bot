## Что за продукт

**Postfactum** — личный торговый журнал с Telegram-ботом и Telegram Mini App.
Бот: `@postfactumTrade_bot`, id 8867032918. Старый бот удалён, его токен не
используется. Пользователь один; интерфейс и рабочая переписка по-русски,
часовой пояс `Asia/Yekaterinburg` (UTC+5), время серверных наблюдений обычно UTC.

Продукт ведёт сделки и исполнения, импортирует позиции/сделки BingX,
показывает статистику и риск, открывает рыночные/лимитные сделки после
подтверждения, управляет стопом, тейком и частичным/полным закрытием,
сверяет состояние биржи и журнала, отправляет уведомления. Встроенная
ИИ-аналитика сейчас использует клиент Anthropic. Переход на Codex касается
разработки; менять ИИ-провайдера бота этой задачей не поручено.

**Поворот продукта 02.10.2026:** сигналы/детекторы и исследование стратегий
убраны: проверка не нашла преимущества. Старые сигнальные таблицы пока
сохранены; это не повод снова включать сигналы. Автономных входов нет.
Стоп обязателен, входы и действия требуют подтверждения пользователя.
Монетизация и другие биржи отложены.

## Инфраструктура и безопасность

VPS Timeweb Cloud, Франкфурт: `147.45.111.10`, `/opt/trading_bot`.
Домен Mini App: `app.postfactumtrade.ru`. Сервисы: bot, api (общий образ),
PostgreSQL 16, Redis 7.4, Caddy 2.10.2. Порты наружу только у Caddy 80/443;
БД, Redis и API не публикуются. Swap 2 ГБ уже включён 17.10 (ранние записи
«swap нет» устарели). Перед сборкой/репетицией available ≥ 700 МБ.
У api лимит 256 МиБ, рабочий порог доклада >230 МиБ, не старые 150/200.
Последний замер api 207.4 МиБ после ~20 ч; bot RssAnon 259.2 МБ после ~24 ч,
лимита нет; это исторические точки, не текущий замер.

`.env`, шифровальный ключ и серверный override из продакшна не переносить в
локальную разработку. ENCRYPTION_KEY прода неизменяем без отдельного плана
перешифрования. Ключи биржи через ExchangeFactory, в логах/отчётах только
разрешённые поля и маски, не весь ответ API: BingX может вернуть apiKey эхом.
Redis `noeviction`: вытеснение лока может нарушить защиту от двойного действия.
