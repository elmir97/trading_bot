- **Полный pytest / smoke ×2:** отсутствуют PostgreSQL, psql и отдельная
  подготовленная БД `trading_bot_test`. Попытка установить системные пакеты
  завершилась ограничением смены UID/GID среды. Тесты на рабочую БД не направлялись,
  skipped не выдавались за успешный гейт.
- **Стенд, браузерные сценарии и снимки:** не запускались без тестовой БД;
  UI и поведение продакшна этой подготовкой не проверялись.
- **Автоматическая загрузка в отдельном клиенте Codex:** конфигурация и
  размер инструкций проверены, но отдельный CLI в контейнере не установлен.
  В локальном клиенте после копирования файлов нужна новая сессия и сводка
  загруженных инструкций по workflow.
- **GitHub, SSH, прод, BingX:** доступ не переносился, соединения не
  выполнялись; текущее состояние сервера берётся только из последнего handoff.
  Коммитов, push, миграций, рестартов и торговых операций не было.
